Project Proposal Information
**Proposal Title**: AI Agent for API Testing & Tool Generation

**Abstract**: Develop an AI Agent leveraging LLMs to automate API testing and tool generation. This includes generating test cases, validating responses, and converting APIs into structured formats for integration with frameworks like crewAI, smolagents, etc. A benchmark dataset will also be built for LLM evaluation to choose the best backend model.

Detailed Description
Traditional API testing requires manual setup of requests and validation logic. This project introduces an AI Agent that takes in natural language test scenarios and automatically produces robust tests. The agent can evaluate API responses, track consistency, and propose performance improvements. It also simplifies the generation of tool definitions compatible with modern AI agent frameworks.
